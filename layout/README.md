# GL1800: точный перевод с сохранением оригинальной вёрстки

**Статус:** экспериментальная ветка `layout-ru`. Здесь **нет** полного перевода
всех 757 страниц по исходным координатам. APK из этой ветки пока не выпускается.

## Почему предыдущая версия не соответствовала задаче

`www/translation_ru.json` содержит постраничный перевод/сжатый пересказ, а
`scripts/build_russian_manual.py` добавлял текст в новые блоки и менял высоту
страниц. Из-за этого подписи не оставались внутри исходных таблиц и рисунков.

## Новый безопасный путь

- `scripts/extract_layout_spans.py` извлекает каждую исходную надпись с координатами.
- Сопоставление `source` / `ru` / `bbox` выполняется отдельно для каждого
  элемента, включая таблицы и векторные подписи на рисунках.
- `scripts/localize_pdf_in_place.py` удаляет только соответствующий
  английский текст и вставляет русский на ту же позицию. Изображения и линии
  таблиц остаются нетронутыми.
- Если русский текст не помещается либо исходная подпись не совпадает,
  генератор пишет ошибку в отчёт QA, а не подставляет произвольный перевод.
- Текст, запечённый в растровые изображения, требует отдельной ручной
  локализации изображения и сверки технических обозначений.

## Проверка

GitHub Actions `layout-ru.yml` создаёт карту координат для 757 страниц,
выполняет автоматический тест сохранения геометрии и генерирует
**двухстраничный проверочный PDF** с переводом настоящих страниц 3 и 7.
Исходные схемы, размеры страниц, таблицы и изображения сохраняются.

Для полного релиза необходимо перевести и сверить каждую из ~33 722
извлечённых надписей, проверить встроенные в рисунки растровые подписи,
технические числа и единицы измерения, затем выполнить визуальную сверку всех
страниц. До этого сборка APK не должна заявляться как полностью русифицированная.
