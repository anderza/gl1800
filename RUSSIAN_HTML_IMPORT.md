# GL1800: готовый HTML с русскими PNG-страницами

Эта ветка предназначена для исходника из пользовательского gl1800.zip: GL1800.exe.html, data.js и 757 готовых русских изображений страниц.

Android APK собирается **только после** проверки русской версии HTML и наличия всех 757 PNG, а не английского manual.pdf.

Для завершения загрузки используются файлы из подготовленного архива GL1800_RU_HTML_Android_GitHub.zip:
- www/index.html (просмотрщик изображений, а не старый PDF-просмотрщик);
- www/data.js (русское оглавление и поиск);
- www/pages-01.zip … www/pages-08.zip (757 русских PNG);
- capacitor.config.json, package.json.

GitHub Actions автоматически распакует изображения, подготовит Capacitor и выпустит GL1800-RU.apk. В этой ветке пока нет больших файлов изображений: их требуется перенести из загруженного в чат архива. Сборка специально завершается ошибкой при их отсутствии, чтобы не выпускать английский APK снова.
